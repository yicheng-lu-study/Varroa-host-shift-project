# Varroa-host-shift-project
Codes for our brand new project
Based on the original work by Nurit Eliash and Alexander Mikheyev, the code in this project was further improved and written under the guidance and assistance of Ye Feng, Alexander Mikheyev, and Maeva A. Techer.

This repository consists of a Snakemake workflow (`Snakefile`), along with several shell scripts and R scripts for data processing and analysis.

## Workflow Source and Modifications

The `Snakefile` in this repository is adapted from the original version developed by **Nurit Eliash** and **Alexander Mikheyev** for the [varroa-pedigree-study](https://github.com/nurit-eliash/varroa-pedigree-study) project.

### Original Workflow
*   **Original Authors**: Nurit Eliash and Alexander Mikheyev
*   **Original Repository**: [https://github.com/nurit-eliash/varroa-pedigree-study](https://github.com/nurit-eliash/varroa-pedigree-study)
*   **Original Project Description**: This repository contains the analysis pipeline for studying varroa mite pedigree data.

### Modifications
This version includes modifications to the original `Snakefile`. For a detailed description of the specific changes, please refer to the **Methods** section of the manuscript associated with this work.

### Usage Notes
The usage of this modified workflow may differ from the original. Please consult the documentation in this repository for setup and execution instructions.
